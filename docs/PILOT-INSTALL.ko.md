# ICC WireGuard Link 시험판

버전: 1.0.11-icc-test.1 (upstream 1.0.11 기반)
목적: AdGuard 광고 차단과 개인 WireGuard 내부망 연결의 동시 사용 시험
서버/개인 설정 및 WireGuard 키는 APK에 포함하지 않습니다.

## 설치 순서
1. 현재 메인폰의 일반 WireGuard 설정 파일을 확보합니다. ICC 앱 내부 터널용 설정이나 다른 기기의 설정을 대신 사용하지 않습니다.
2. 유니콘 보호와 기존 WireGuard 연결을 끕니다. 두 앱을 삭제할 필요는 없습니다.
3. 공식 AdGuard 광고 차단 앱을 설치하고 보호를 켭니다. 별도 AdGuard VPN 앱은 필요하지 않습니다.
4. 이 시험 APK를 설치합니다. 공식 AdGuard VPN 또는 원본 WireGuard Link가 이미 설치돼 있으면 같은 패키지명/서명 충돌이 생길 수 있습니다. 이 경우 기존 설정부터 내보내 보관한 뒤 이전해야 합니다.
5. 시험 앱에서 메인폰용 .conf를 가져오고 해당 터널을 선택합니다. 'AdG 통합'을 켜고 연결합니다.
6. Android가 요청하는 VPN/알림 권한을 허용하고, AdGuard 보호와 연동 상태를 확인합니다.
7. ICC, KodBox, Termix를 열어 실제 접속을 확인합니다. '연결됨' 표시만으로 서버 연결이 확인된 것은 아닙니다.

## 시험 항목
- 일반 웹 사용 시 광고 차단과 인터넷 연결 유지
- WG 내부 서비스 로그인/파일 다운로드
- 화면 꺼짐 후 다시 접속, Wi-Fi 끊었다 다시 연결
- Wi-Fi와 모바일 데이터 전환 후 자동 복구
- 사진백업을 AdGuard에서 제외했을 때 기존 업로드 속도 유지

처음에는 설정 변경을 최소화하고, 연결 성공 뒤 배터리/장시간 유지 시험을 진행합니다.
기존 WireGuard 앱과 시험 앱에서 같은 설정으로 동시에 연결하지 마세요.
문제가 있으면 시험 앱 연결과 AdGuard 보호를 끄고 기존 유니콘/WireGuard를 다시 켜면 됩니다.
이 시험판에는 우리 서버로 로그 보내기 기능을 추가하지 않았습니다. 상태/오류 문구와 발생 시각을 알려주세요. 설정의 PrivateKey/PresharedKey는 공유하지 마세요.

소스: https://github.com/apzzzz1234/wireguard-link-for-adg
이 앱은 AdGuard/WireGuard의 공식 제품이 아닙니다. 실제 휴대폰의 백그라운드 안정성과 배터리는 시험 대상입니다.
